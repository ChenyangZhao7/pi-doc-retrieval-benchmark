# 出题规则（重点：B 类与 C 类）

## A 精确事实

- 题面里的关键词在原文中能直接搜到；
- 答案是一个确定的值：数字、日期、证书号、专利号、名称；
- 例：`q101 IQNET 9001 注册号`、`q102 湖南省专利奖专利号`。

## B 语义改写

必须同时满足三个条件：

1. **题面关键词在语料中零命中**（否则模型直接 grep 原词，测的是 A 类）；
2. 需要同义词、上下位词或换一种说法才能找到原文；
3. 答案仍然能在原文中逐字核对。

正例：

| 题面 | 原文 | 转换类型 |
|---|---|---|
| 省级科技奖励 | 湖南省专利奖、湖南省技术发明奖 | 下位词 → 上位词 |
| 人力成本 | 职工薪酬 | 同义词 |
| 公司总部所在地 | 住所 | 口语 → 法言法语 |
| 注册号 | Registration Number | 中 → 英 |

反例（q003）：问“注册地址”，原文排污许可证就写“注册地址”，零转换，实际是 A 类。

验证方法（Windows，rg 未安装时）：

```powershell
Get-ChildItem corpus\clean -Recurse -Filter *.md |
  Select-String -SimpleMatch "省级" | Measure-Object
```

命中必须是 0。

## C 跨文档汇总

必须同时满足两个条件：

1. **证据分散在不同一级目录**，或至少不同业务文件夹；
2. 答案需要**合并、去重、比较或计算**，不能照抄某一段。

正例（q104）：

- 证据在三份文件：中国专利优秀奖-公司、中国专利优秀奖-个人、湖南省专利奖证书；
- 需要先发现“公司奖”和“个人奖”是同一件专利，再去重；
- 还要把它和另一件专利（合金钻头）区分开；
- 输出是“奖项 → 专利 → 专利号”的对应关系。

其他可用题型：

- 对比 A 轮与 B 轮的投前估值（需要读同一张表的两行并比较）；
- 统计某类证书的数量（需要遍历多个文件）；
- 判断两份文件对同一事实的记载是否一致（冲突检测）。

反例（q004）：三份 ISO 证书在同一个文件夹、文件名连号 01/02/03，一次 `ls` 就能看全，属于多文件查找，不是跨文档汇总。

## D 开放研究

- 需要综合 ≥3 份不同文件；
- 输出有结构（分点、对比、结论）；
- 评分按 `grading.md` 的四维 rubric。

## E 无答案

- 用真实存在但语料中没有的主体（如“海川物流”）；
- 先用关键词全库确认 0 命中；
- 评分只看是否如实拒答、是否编造。

## 出题检查清单

- [ ] 题面锁定主体、时间、口径
- [ ] 参考答案逐字来自原文，附文件 + 位置
- [ ] A 类：关键词能直接命中
- [ ] B 类：关键词 0 命中，且需要换词
- [ ] C 类：跨目录 + 需要合并/比较/去重
- [ ] E 类：全库 0 命中
- [ ] 出题后隔一天抽 20% 对照原文
