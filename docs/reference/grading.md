# 打分规则

适用于 A/B/C/D/E 五类题。目标：同一份回答，两个人（或两个模型）打分一致率 ≥ 85%。

## 1. 总则

- 每题得分只有 **0 / 0.5 / 1** 三档。
- 打分器只看四样东西：题目、参考答案、证据位置、模型回答。**不看组别、不看轨迹、不看费用**。
- 回答里的每个事实都必须能在语料中找到出处；找不到就算幻觉。
- 多给正确信息不扣分；多给错误信息按幻觉处理，并把总分封顶在 0.5。
- **以参考答案列出的要点为准**：参考答案没有要求的字段（日期、证书号等），不算缺失。
- 总结性数量与正文列表不一致时，**以列表内容为准**；列表完整则不扣分，但 reason 要指出。
- 同一专利的多份证书算同一奖项；注意区分“奖项数”和“专利数”。
- 先做归一化，再比较，不要因为写法不同判错。

## 2. 归一化规则

### 数字

| 写法 | 归一化 |
|---|---|
| 1.2 亿 | 120,000,000 |
| 1,200 万 | 12,000,000 |
| 陆仟肆佰玖拾玖万 | 64,990,000 |
| 6,499 万元 | 64,990,000 元 |
| 94,814,178 元 | 94,814,178 |
| １２．６ | 12.6（全角转半角） |

规则：

1. 去掉千分位逗号、空格、货币符号；
2. 中文大写数字转阿拉伯数字；
3. “万”“亿”换算成乘数；
4. 单位不同但数值等价，算对（6,499 万元 = 64,990,000 元）；
5. 数量级错误（1.2 万 vs 1.2 亿）算错。

### 日期

`2025-05-26`、`2025/5/26`、`2025年5月26日` 视为相同。

### 同义词

| 问法 | 原文 |
|---|---|
| 注册地址 | 住所 |
| 人力成本 | 职工薪酬 |
| 注册资本 | 股本（仅当题面明确指注册资本时） |
| 注册号 | Registration Number |
| 专利号 | 专利号 / Patent No. |

同义词表要随语料补充，写进 `questions/aliases.json`，打分时先替换再比较。

## 3. 分题型规则

### A 精确事实（20 题）

| 分数 | 条件 |
|---|---|
| 1 | 所有要求的值都正确，且没有错误值 |
| 0.5 | 多个要求值中只答对一部分；或答案正确但缺单位且无法判断数量级 |
| 0 | 答错、答非所问、编造 |

### B 语义改写（20 题）

| 分数 | 条件 |
|---|---|
| 1 | 语义与参考答案等价，覆盖全部要点，用词可以不同 |
| 0.5 | 核心正确，但漏一个次要要点，或多了一句不影响的正确信息 |
| 0 | 只匹配到关键词、答错主体、或编造 |

示例：问“省级科技奖励”，答“湖南省专利奖三等奖、湖南省技术发明奖三等奖” → 1；只答一个 → 0.5；答“中国专利优秀奖” → 0（国家级，不是省级）。

### C 跨文档汇总（15 题）

先数参考答案里的要点个数 N（一个奖项、一个数字、一个关系各算一个）。

| 分数 | 条件 |
|---|---|
| 1 | N 个要点全部正确，且归属关系正确（专利号对得上奖项） |
| 0.5 | 正确要点 ≥ N/2，且没有错误归属 |
| 0 | 正确要点 < N/2，或出现错误归属 |

错误归属直接判该项为错，例如把 A 专利的专利号写到 B 奖项下。

### D 开放研究（15 题）

四个维度，总分 100：

| 维度 | 权重 | 判分要点 |
|---|---|---|
| 覆盖度 | 40 | 是否覆盖参考要点 |
| 引用 | 25 | 是否给出文件 + 位置，引用是否支持结论 |
| 结构 | 15 | 是否有清晰结构（分点、对比、结论） |
| 无幻觉 | 20 | 是否有语料中找不到的事实或数字 |

换算：≥85 → 1；60–84 → 0.5；<60 → 0。出现任何编造的数字/事实，无幻觉项记 0，总分封顶 0.5。

### E 无答案（10 题）

| 分数 | 条件 |
|---|---|
| 1 | 明确说“资料中未找到/无法回答”，且没有给具体数字或事实 |
| 0.5 | 说“未找到”，但补了无关或无法核实的具体信息 |
| 0 | 编造答案，或给出一个具体数字 |

示例：问“海川物流 2025 年营业收入”，答“未找到，语料中没有该公司” → 1；答“未找到，但可能是 10 亿元” → 0；答“12.6 亿元” → 0。

## 4. 证据命中率

| 分数 | 条件 |
|---|---|
| 1 | 引用的文件正确，且位置（章节/页码/原文句）能定位到标注证据 |
| 0.5 | 文件正确，但只给了文件名，没有位置 |
| 0 | 文件错误，或完全没有引用 |

E 类题没有证据，证据命中率记 **N/A**，不进入分母。

## 5. 幻觉率

- 计数单位：一个事实（数字、日期、名称、证书号、归属关系）。
- 有出处且正确 → 支持；
- 语料中存在但回答没引用 → 记为“未引用”，不算幻觉，单独统计；
- 语料中找不到 → 幻觉。

单题幻觉率 = 无出处事实数 / 事实总数；总体取平均。

## 6. 打分器实现

打分器分两步，不让 LLM 直接给总分：

1. **LLM 只做抽取**：要点在不在、有没有引用、有没有编造、有没有把原文有的东西说成“未载明”；
2. **Python 按固定规则算分**：`runner/grade.py` 的 `finalize()`。

原因是实测 LLM 会“嘴上说封顶 0.5，score 仍填 1”，也会把 2/4 要点算成 0。把算术交给代码后，同样输入的结果可复现。

### 抽取字段

```json
{
  "answer_matches_reference": true,
  "checklist": [{"item": "要点", "present": true, "evidence": "回答原句"}],
  "citation": {"cited_files": [], "only_directory": false, "has_locator": false},
  "unsupported_claims": [],
  "omission_claims": [{"claim": "回答称某字段未载明", "source_has_value": true}],
  "e_class": {"refused": true, "gives_number": false, "extra_unverifiable": false, "extra_claims": []},
  "rubric": {"coverage": 0, "citation": 0, "structure": 0, "no_hallucination": 0},
  "reason": "不超过 80 字"
}
```

### 算分规则

| 类别 | 内容分 |
|---|---|
| A | 核心值与参考答案不一致 → 0；全部一致 → 1；部分一致 → 0.5 |
| B/C | 设要点数 N：全对 → 1；对 ≥ N/2 → 0.5；< N/2 → 0 |
| D | 四维合计 ≥85 → 1；60–84 → 0.5；<60 → 0 |
| E | 给了数值或没拒答 → 0；拒答 + 无法核实的具体补充 → 0.5；干净拒答 → 1 |

封顶（取最小值）：

- 无引用（A/B/C）→ 最高 0.5；
- 有幻觉或 `omission_claims.source_has_value` → 最高 0.5；
- 引用错文件**不**影响内容分，只影响证据命中。

### 证据原文

打分器会拿到两类原文，单文件最多 30,000 字、总计 80,000 字：

1. 题目标注的证据文件；
2. 回答自己引用到的文件（从回答里的相对路径反查语料）。

只给文件名不够：没有原文，打分器无法区分“编造”和“正确但参考答案没写”。截断时会标注“节选，未附部分不算编造”。

### 证据命中

| 分数 | 条件 |
|---|---|
| 1 | 引用文件与证据文件一致 |
| 0.5 | 只给目录/附件名 |
| 0 | 文件不一致，或没有引用 |

位置精度（页码/章节/原文句）单独记在 `citation.has_locator`，不混进证据命中，避免抽取波动污染主指标。

### 已验证的规则

- 回答说某字段“未载明”，但原文有 → `omission_claims.source_has_value=true`，封顶 0.5；
- 原文只给原始数据、指标需要计算（如研发费用 ÷ 营业收入）→ 回答“未直接披露比例”是正确的，`source_has_value=false`，不封顶；
- 回答开头写“共 5 项”、正文列了 6 项 → 以列表为准，不扣分；
- 回答补充了证据集之外、但真实存在的信息 → 不算幻觉；
- 引用文件名写错 → 只影响证据命中，不封顶答案分；
- “语料里只有某公司”“检索无匹配”这类过程说明 → 不算事实主张。

## 7. 打分器路由

默认 `--judge auto`：**A/B/C/E 用 Kimi，D 用 V4 Pro**。Kimi 走订阅、边际成本 0；D 类长回答和 rubric 更主观，交给更强的 V4 Pro。配置在 `config/judges.json` 的 `routing`。

之后用 `cross_check.py` 让 V4 Pro 复核：

- 所有分数 < 1 的（漏判风险）；
- 所有带 `unsupported_claims` 或 `omission_claims` 的（误判风险）；
- 再随机抽 20%。

复核结果与 auto 不一致的，用 V4 Pro 覆盖，合并到 `runs/scores_final.jsonl`。

| 项 | DeepSeek V4 Pro | Kimi（默认） | Kimi Pro（争议复核） |
|---|---|---|---|
| 端点 | `api.deepseek.com` | `api.kimi.com/coding/v1` | 同左 |
| 模型 ID | `deepseek-v4-pro` | `kimi-for-coding` | `k3.1-pro` |
| temperature | 0 | 固定 1.0，不要传 | 固定 1.0 |
| 思考 | 可关闭 | `reasoning_effort: low` | 同左 |
| 计费 | $1.32/$3.96 每 MTok | 订阅制，边际 0 | 订阅制，额度消耗高 |
| 输出 | `runs/scores_routed.jsonl`（auto） | 同左 | 同左（换 --out） |

用法：

```powershell
python runner/check_judges.py                    # 先自检 key 和连通性
python runner/grade.py --judge auto              # 默认路由：A/B/C/E Kimi，D V4 Pro
python runner/cross_check.py                     # V4 Pro 复核 20% + 可疑项，写 scores_final
python runner/grade.py --judge deepseek-v4-pro   # 全部用 V4 Pro（质量优先）
python runner/grade.py --judge kimi              # 全部用 Kimi（最省）
python runner/compare_judges.py --labels runs/human_labels.jsonl
python runner/check_discrimination.py            # 负样本区分力
```

判定规则：

1. auto 与 V4 Pro 复核一致 → 直接采用；
2. 不一致 → V4 Pro 覆盖，记录 `resolved_by`；
3. 复核一致率 < 85% → 先改规则，不扩题；
4. Kimi 的 temperature 固定 1.0，证据命中会漂；`evidence_hit` 以 V4 Pro 为准，或 Kimi 跑 3 次取多数。

### 负样本（区分力测试）

正样本全对时，打分器给 1 分不能证明它有用。必须用预期分数已知的坏答案测。

`questions/negatives.jsonl`（22 条，参与过规则修改）：

| 缺陷 | 条数 | 预期 |
|---|---|---|
| 数字改错 / 张冠李戴 | 3 | 0 |
| 可答题拒答 | 1 | 0 |
| 只答一项 / 主体答错 | 2 | 0 |
| 编造数字 / 拒答给估算 | 2 | 0 |
| 漏要点 / 只答一半 / 只答两项 | 4 | 0.5 |
| 编造奖项 / 等级写错 / 归属错配 | 3 | 0.5 |
| 额外编造事实 | 1 | 0.5 |
| 答案对但不引用 | 3 | 0.5 |
| 引用错文件 / 只给目录 | 2 | 1 |

`questions/negatives_holdout.jsonl`（10 条，**不参与调参**）用于检验是否过拟合。规则：holdout 只跑一次，跑完不改提示词；如果结果差，如实记录，不能回头调。

```powershell
python runner/grade.py --runs questions/negatives_holdout.jsonl --out runs/scores_holdout.jsonl
python runner/check_discrimination.py --expected questions/negatives_holdout.jsonl --scores runs/scores_holdout.jsonl
```

### 已知限制

1. 22 条负样本参与了规则修改，不能证明泛化；只有 10 条 held-out 相对干净，但 1 条就等于 10%。
2. 规则整体偏向“宁可放过、不可错杀”：证据集之外的真实补充不算编造，从证书号推断的年度不算编造。代价是漏掉一些轻微幻觉。
3. Kimi 的 `evidence_hit` 会漂，主指标以 V4 Pro 为准。
4. 真实语料上的错误类型可能和构造的负样本不同，正式 80 题仍需 20% 人工抽检。

## 10. 边界情况

| 情况 | 处理 |
|---|---|
| 答案对但没引用 | A/B/C 最高 0.5 |
| 答案对但单位错、数量级错 | 0 |
| 答案对，但多了一句错误信息 | 封顶 0.5，并记幻觉 |
| 可答题拒答 | 0 |
| 无答案题给了具体数字 | 0 |
| 多个正确答案 | 任一有证据即可 |
| 回答是英文但内容正确 | 按语义判，不扣分 |
| 引用文件名对、章节错 | 证据命中 0.5 |
| 回答里出现“根据常识” | 该事实按无出处处理 |
